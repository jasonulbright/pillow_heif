This wheel is a decode-only build made by https://github.com/jasonulbright/pillow_heif.
It carries no HEVC encoder. It combines the libraries listed here.

Name: libheif
License: LGPLv3 (see COPYING.libheif)
Version: 1.23.7
  Source code: https://github.com/strukturag/libheif/releases/download/v1.23.7/libheif-1.23.7.tar.gz

Name: libde265
License: LGPLv3 (see COPYING.libde265)
Version: 1.1.3
  Source code: https://github.com/strukturag/libde265/releases/download/v1.1.3/libde265-1.1.3.tar.gz

Both libraries are built from the unmodified release archives above, as shared
libraries that you can replace. The build scripts are in the spectra/ directory
of the repository.

Built in the manylinux_2_28 image. libstdc++ and libgcc come from the host system.
